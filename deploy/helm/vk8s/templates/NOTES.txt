vk8s {{ .Chart.AppVersion }} 已安装到 namespace {{ .Release.Namespace }}。

1. DNS 记录（安装后必须完成）

   取 gateway 的 LoadBalancer 地址：
     kubectl -n {{ .Release.Namespace }} get svc vk8s-gateway -o jsonpath='{.status.loadBalancer.ingress[0].ip}{.status.loadBalancer.ingress[0].hostname}'
   取宿主 Ingress Controller 的 LoadBalancer 地址（例如 ingress-nginx）：
     kubectl -n ingress-nginx get svc ingress-nginx-controller -o jsonpath='{.status.loadBalancer.ingress[0].ip}{.status.loadBalancer.ingress[0].hostname}'

   然后添加：
     *.{{ .Values.apiDomain }}            A/CNAME  → gateway 的 LB 地址        （kubectl 流量，L4 SNI 透传）
     {{ include "vk8s.consoleHost" . }}   A/CNAME  → Ingress Controller 的 LB 地址（Web UI / API；具体记录优先于泛记录）
     *.{{ .Values.appsDomain }}           A/CNAME  → Ingress Controller 的 LB 地址（用户工作负载）

2. 首次登录

{{- if .Values.auth.bootstrapAdmin.enabled }}
   管理员用户名：{{ .Values.auth.bootstrapAdmin.username }}
   密码：
     kubectl -n {{ .Release.Namespace }} get secret {{ include "vk8s.bootstrapAdminSecretName" . }} -o jsonpath='{.data.password}' | base64 -d; echo

{{- else }}

     kubectl apply -f - <<EOF
     apiVersion: vk8s.io/v1alpha1
     kind: User
     metadata: {name: admin}
     spec: {role: admin, auth: {static: {passwordSecretRef: {name: user-admin}}}}
     EOF
{{- end }}

3. 建集群与下载 kubeconfig

   登录 Web UI → 「我的集群」→ 新建 → 等待 Running → 「下载 kubeconfig」。
   或者命令行：
     kubectl get virtualclusters
     kubectl get vc <name> -o jsonpath='{.status.phase}'

4. CRD 升级提醒

   crds/ 目录中的 CRD 只在 helm install 时安装；helm upgrade 不会更新它们。升级 chart 时请先：
     kubectl apply -f deploy/helm/vk8s/crds/
